# 🧠 Rule-Based Recommendation System

A responsive frontend web application that simulates a **Rule-Based Recommendation System**. This project allows users to manage product categories, add products, track likes and views, and generate recommendations based on predefined rules. All data is stored locally using the browser's Local Storage.

---

## 📌 Features

- 📊 Interactive Dashboard
- 📂 Manage Categories
- ➕ Add New Items
- 📦 View All Items
- ❤️ Like Products
- 👁️ Track Product Views
- 🤖 Rule-Based Recommendation Engine
- 💾 Local Storage Support (No Database Required)
- 📱 Responsive User Interface

## 📷 Application Modules

### 🏠 Dashboard
- Displays total items
- Shows total views
- Shows total likes
- Displays total categories

### 📂 Categories
- Create new categories
- View existing categories

### ➕ Add Item
- Add products
- Assign category
- Store data in Local Storage

### 📦 Items
- Display all products
- Like products
- View products
- Delete products (if implemented)

### 🤖 Recommendation
- Generates recommendations based on predefined rules
- Uses likes, views, and categories for recommendations

---

## 💾 Data Storage

The application uses **Browser Local Storage** to store:

- Categories
- Products
- Likes
- Views
- Recommendation Data

No backend or database is required.

---

## 🎯 Recommendation Logic

The recommendation system uses simple rule-based conditions such as:

- Products with higher likes are prioritized.
- Frequently viewed products receive higher recommendations.
- Category matching improves recommendation relevance.
- Newly added products are also displayed.
